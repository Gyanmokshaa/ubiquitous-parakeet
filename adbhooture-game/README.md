# অদ্ভুতুড়ে: রাত বারোটার কলকাতা

[অদ্ভুতুড়ে](https://facebook.com/Adbhooture) পেজের জন্য মোবাইলে খেলার মতো একটা বাংলা ভৌতিক গল্প-খেলা।
শ্রাবণ, তেরোশো নব্বই। লোডশেডিংয়ের রাত, উত্তর কলকাতার পুরনো বাড়ি, বন্ধ সিনেমা হল, আর একটা লাইন-কাটা টেলিফোন, যেটা বাজার কথা নয়।

~ সুচন্দ্রা দাস

## খেলা চালানো

কোনো বিল্ড লাগে না। ফোল্ডারটা যে-কোনো স্ট্যাটিক সার্ভার দিয়ে খুললেই হবে, যেমন:

```bash
cd adbhooture-game && python3 -m http.server 8000
```

তারপর ফোনে বা ব্রাউজারে `http://localhost:8000` খোলো। একবার খোলার পরে সার্ভিস ওয়ার্কার সব ফাইল রেখে দেয়, তাই এরপর অফলাইনেও খেলা যায়।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `story.js` | পুরো কাহিনি: ৮৪টা দৃশ্য, ১১টা সমাপ্তি (একটা গোপন) |
| `game.js` | ইঞ্জিন, শর্ত, ভয়ের মাত্রা, সংরক্ষণ, পর্দা |
| `art.js` | কোডে আঁকা SVG ছবি |
| `audio.js` | Web Audio দিয়ে তৈরি শব্দ (শুরুতে বন্ধ থাকে) |
| `share.js` | প্রতিটা সমাপ্তির শেয়ার-কার্ড (canvas) |
| `sw.js`, `manifest.webmanifest` | অফলাইন খেলা |
| `tools/validate.js` | প্রতিটা পথ হেঁটে দেখে কোনো ভাঙা লিংক বা কানাগলি আছে কি না, সব সমাপ্তিতে পৌঁছনো যায় কি না |
| `tools/playtest.js` | ফোন-মাপে আসল ব্রাউজারে এলোমেলো খেলে ত্রুটি আর আড়াআড়ি স্ক্রল খোঁজে |

## যাচাই

```bash
node adbhooture-game/tools/validate.js
```

```bash
node adbhooture-game/tools/playtest.js 6
```

ডিবাগের জন্য `?node=n_317` দিয়ে সরাসরি কোনো দৃশ্যে যাওয়া যায়, `?reset=1` দিয়ে সব সংরক্ষণ মুছে দেওয়া যায়।

## গোপন সমাপ্তি

প্রথম রাতে এটা খোলে না। আগের রাতগুলোয় যা জেনেছ (ফোনের ওপারের মেয়েটা কে, আর রূপছায়ার শেষ রিলের কথা), সেটা মনে থাকে, আর পরের রাতে ফোন ধরলে নতুন একটা প্রশ্ন করার সুযোগ আসে।

সব কাহিনি ও চরিত্র কাল্পনিক।
